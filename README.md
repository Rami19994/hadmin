# لوحة تحكم الإدارة الشاملة — H-store (`admin 1`)

تطبيق ويب مستقل وجاهز للرفع المباشر على **Vercel**، يوفّر للمشرف العام (`role = 'admin'`) تحكماً كاملاً بجميع تفاصيل تطبيق **H-store** (عرض، بحث، فلترة، إضافة، تعديل، وحذف).

## الأقسام المشمولة في لوحة الإدارة
1. **لوحة المؤشرات والمراجعة الفورية**: إحصائيات المتاجر، إيرادات الاشتراكات بالدولار، إجمالي الفواتير حسب كل عملة، وطوابير الاعتماد السريع بنقرة واحدة.
2. **المتاجر والتراخيص (`stores`)**: إنشاء، اعتماد، رفض، إيقاف، تعديل كافة الحقول (المالك، الدولة والعملة، الإحداثيات والخريطة، الضريبة، طرق الدفع، أرقام الهواتف المتعددة، الرخصة التجارية، الشعار، وحصص الصور)، تعبئة الأقسام الإلزامية، والحذف الكامل.
3. **الاشتراكات والخطط السنوية (`store_subscriptions`)**: منح وتعديل وحذف اشتراكات المتاجر (`$100` / `$300` / `$800`) وزيادة باقات الصور الإضافية (`+500` صورة).
4. **الأقسام الإلزامية والفرعية (`store_categories`)**: ترتيب الأقسام، إخفاء/إظهار الأقسام الإلزامية، تعبئة الأقسام الناقصة، تعديل الرموز والصور، والحذف.
5. **المواد والبضائع والوحدات (`products`)**: إضافة وتعديل وحذف واستنساخ المواد، التحكم بالتوفر والأسعار والمصدر، ومحرر كامل لوحدات البيع الإضافية (`extra_units`).
6. **العروض والتخفيضات (`promotions`)**: تحكم كامل بقسمي «العروض» و«التخفيضات» والعدادات والكميات المباعة ونسب الخصم.
7. **شريط العروض اليومية ٢٤ ساعة (`daily_offers`)**: نشر، تعديل، تمديد +٢٤ ساعة، وتنظيف المنتهي.
8. **الطلبات والفواتير التفاعلية (`orders` + `order_items`)**: تعديل حالة وترويسة أي فاتورة، إضافة/تعديل/حذف بنود الفاتورة، وضع خط أحمر «غير متوفر»، إضافة مواد بديلة، وطباعة الفاتورة.
9. **دفتر «على الحساب» والقيود المالية (`credit_accounts` + `credit_entries`)**: اعتماد الدفاتر، تعديل سقف الدين، ترحيل قيود الشحن والسداد ذرياً، وحذف القيود الخاطئة مع إعادة احتساب الرصيد التراكمي تلقائياً.
10. **المستخدمون، التجار، المشرفون، والعناوين (`profiles` + `consumer_addresses`)**: توثيق الهويات (`identified`)، ترقية الصلاحيات إلى `admin`/`merchant`، مراجعة صور الوثائق، إدارة عناوين التوصيل، وحذف الحسابات نهائياً.
11. **سلال المتسوقين، المفضلة، واليوميات (`carts`, `favourites`, `shopper_layouts`)**: معاينة وتعديل السلال المفتوحة، المفضلة، والمشتريات اليومية (♥).
12. **إعلانات الصفحة الرئيسية (`adverts`)**: إنشاء وجدولة وتعديل البنرات الإعلانية الموجهة حسب الدولة والمحافظات.
13. **إعدادات المنصة ومتصفح التخزين (`app_settings` + `catalog` Storage)**: التحكم بالاعتماد التلقائي للمتاجر، التحديث الإجباري، قنوات تواصل H، وتصفح/رفع/حذف ملفات دلو الصور `catalog`.

## خطوات التشغيل والربط على Vercel (خلال دقيقتين)

### ١. تفعيل صلاحيات الإدارة في Supabase
افتح **Supabase Dashboard -> SQL Editor** وشغّل محتوى الملف:
- `supabase/0013_admin_full_control.sql`

### ٢. النشر على Vercel
1. اربط مستودع GitHub (`https://github.com/Rami19994/hadmin.git`) بمشروع جديد على **Vercel**.
2. الإعدادات جاهزة تلقائياً عبر `vercel.json` (`Framework: Vite`, `Output Directory: dist`).
3. *(اختياري)* لإتاحة إنشاء مستخدمين جدد بكلمة مرور مباشرة من اللوحة عبر `/api/admin-auth`، أضف المتغير السري التالي في **Vercel -> Settings -> Environment Variables**:
   - `SUPABASE_SERVICE_ROLE_KEY` = مفتاح `service_role` من لوحة Supabase *(بدون بادئة `VITE_` إطلاقاً)*.

### ٣. تسجيل دخول أول مشرف
افتح رابط لوحة الإدارة وسجّل الدخول ببريدك وكلمة مرورك، ثم اضغط زر **«تفعيل حسابي كأول مشرف عام الآن»** (أو نفّذ سطر الترقية المعروض على الشاشة في SQL Editor).
